# Stun Slam (Fabric, Minecraft 26.2)

Voll-automatischer Stun Slam. Du musst nicht selbst schlagen.

- G: an/aus
- H: Modus wechseln (Smart / Immer Combo)
- K: Wartezeit zwischen Axt und Mace laenger (1 Tick = 50 ms)
- J: Wartezeit kuerzer (0 = beide Schlaege im selben Tick)

Hotbar: Axt und Mace.
Nach jedem Combo zeigt der Chat die verwendete Wartezeit und die Fallhoehe.
